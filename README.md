This is a passion project that brings together three of my favorite things: **Limbus Company**, **Programming**, and **Roguelites**. 

In this game, I'm applying game development logic to create a survivor-style experience within the Limbus universe.

---

## 🎮 How to Play

1. **Download the files**: Ensure everything is kept inside the `LimbusSurvivors` folder to maintain correct file paths.
2. **Install Dependencies**: Make sure you have Pygame installed:
   ```bash
   pip install pygame

3. **Run the Game**: Open your terminal inside the project folder and run:

python pygameLimbusSurvivors.py
---

## 🕹️ Controls

* **Move**: Use the **Arrow Keys** (`UP`, `DOWN`, `LEFT`, `RIGHT`)
* **Exit**: Press **ESC** to close the game.
